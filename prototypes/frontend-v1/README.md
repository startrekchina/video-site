# 前端高保真原型 v1

> 原型代码，随时可以丢弃。不要被正式代码引用，也不要在这上面继续开发成正式功能。

## 要验证的问题

1. chanhdai.com 的视觉语言（居中带边框的内容列、贯穿全屏的细线、斜纹分隔带、zinc 单色、等宽小注释、“图纸标题栏”式页脚）能不能撑起一个以海报为主的观看站，而不只是个人主页。
2. `docs/requirements.md` 的 v1 用户故事能不能落到一套完整、不打架的页面和导航结构里。
3. ArtPlayer 在这套风格里的样子，以及中英字幕切换、续播、下一集提示、键盘操作的交互细节。

## 运行

需要 Node 22+、pnpm，以及 PATH 上可用的 `bash` 和 `ffmpeg`（首次启动时生成测试视频）。

```bash
cd prototypes/frontend-v1
pnpm install
pnpm dev          # http://localhost:6120（监听 0.0.0.0，局域网可访问）
```

`pnpm build` 会先做类型检查再打包。测试视频 `src/media/test-clip.mp4` 是用 ffmpeg 生成的 60 秒测试图（H.264 + AAC，faststart），不提交到 git；字幕 VTT 已提交。所有单集和电影都播放同一段测试片段。

## 怎么用

左上角琥珀色的 **PROTO** 按钮是原型控制台，只在开发模式出现，样式故意和站点不同。它可以：

- 切换身份场景：访客、新成员（空数据）、成员 `picard_fan`（有观看记录、收藏、片单）、管理员 `station_keeper`。
- 直接跳到各个页面和状态，例如过期邀请码、缺中文简介的电影、重置链接。

数据全部在内存里，刷新就重置（只有所选场景会保留在 sessionStorage）。人物都是虚构的。

演示用的输入：

| 场景 | 输入 |
| --- | --- |
| 登录密码 | `engage`，输错 3 次会出现人机验证占位 |
| 二步验证码 | `123456` |
| 有效邀请码 | `Q-CONT-INUM-01` |
| 已用 / 作废 / 过期邀请码 | `MAKEIT-SO9-3HDR` / `WARP-F8TZ-11NB` / `BORG-X0X0-7777` |
| 恢复码 | 任意 `xxxxx-xxxx` 格式 |

快捷键：`⌘K` / `Ctrl+K` 或 `/` 打开搜索，`D` 切换深浅色。播放页：空格、方向键、`F` 全屏、`M` 静音、`C` 切换字幕。

## 取舍和待定

- 技术栈用 Vite + React Router 7（库模式）+ Tailwind 4 + Base UI，UI 组件从 chanhdai.com（MIT）的 shadcn `base-nova` 组件复制过来。正式版用 React Router 框架模式跑在 Workers 上，届时重写，不直接搬这里的代码。
- 版式按参考站逐页对齐：所有页面与顶栏、页脚统一用 `max-w-3xl` 的内容列。只有剧集和电影浏览页沿用参考站 Blocks 页的宽布局（`container`，顶栏和页脚随之变宽）。列表页用 PageHeading（小标签 + 4xl 标题），作品页和播放页用博客详情页的“← 返回 + 前后切换 + 4xl 标题”，访客页用 login-01 的居中 Card，404 用等宽大号数字。
- 字体统一用 Noto Sans SC（可变字重，自托管 `@fontsource-variable/noto-sans-sc`），正文和标题都用它；等宽角色（集号、时长、邀请码、TOTP、小号大写标签）继续用 Geist Mono，其中的中文字符回落到 Noto Sans SC。字重照参考站：正文 400，标题、导航、标签 500，不用粗体；大标题保留参考站的收紧字距，但减半到 `-0.0125em`，避免中文挤在一起。
- 可交互控件按参考站做成方块：按钮、输入框、菜单项是 8px 圆角的小方块；分段切换（字幕、管理后台标签页）是一个带边框的方框，用 1px 竖线分成格子，当前项灰底；季选择条和分类条一样，是贴着横线的格子；进度条是直角平条。小标签（已开启、管理员等）沿用参考站 Tag 的胶囊形，海报保留圆角。
- 海报在桌面端默认灰度、悬停恢复彩色，照搬参考站的博客卡片；触屏设备始终显示彩色。
- 从参考站的 [组件库](https://chanhdai.com/components) 引入了 10 个组件，只用在已有功能上：
  - Copy Button：邀请链接、重置链接、恢复码。
  - Status Button：生成邀请码、修改密码、添加通行密钥、登录。
  - Scroll Fade：季选择条、成员表格、搜索列表。
  - Middle Truncation：重置链接。
  - Theme Switcher：页脚，三档“跟随系统、浅色、深色”。
  - Swipe Actions：片单条目，左滑移除、右滑排序。
  - Line Nav：账号页右侧，宽屏才显示。
  - Shimmering Text：播放页签发 token 时的占位。
  - Chevrons Up Down：“加入片单”下拉。
  - Timescale：剧集和电影浏览页的“时间轴”视图，按首映年份排列。

  新增依赖 `motion` 和 `@ncdai/react-swipe-actions`。参考站复制按钮的音效和震动反馈没有引入。
- 触屏设备上片单的上移、下移按钮隐藏，改用右滑；移除按钮始终保留，给键盘和读屏用户用。
- 时间轴视图不在需求文档里，是站长要求试做、看效果的。观看热力图同样不在需求里，站长决定不做。
- 异步操作（生成邀请码、添加通行密钥等）在原型里人为延迟约 0.7 秒，好让加载状态看得见。
- 手机底部悬浮胶囊是“搜索 + 菜单”，菜单弹出页面列表；右下角有回到顶部按钮。原型控制台因此挪到了左上角。
- 播放 token、限流、Turnstile、WebAuthn 都只是界面占位，没有真实逻辑。
- 进度上报间隔 15 秒、看完阈值 90%、邀请额度 2、恢复码 10 个，都用需求文档里的默认值。
- 单集标题、简介和集数是按 TMDB 结构生成的示例数据；海报和作品中英文标题来自 `public/assets/posters/star-trek/manifest.json`。
