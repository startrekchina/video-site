# video-site

星际迷航中国（StarTrekChina）粉丝社区的邀请制私人观看站，计划部署在 `video.startrekchina.org`。

## 当前状态

v1 产品范围已确认，前端原型已完成质量与开发准备度评估，成熟的视觉方向、页面结构和主要交互可作为正式工程基准。后端方案已补充，部分业务规则与实现策略仍待确认；正式应用尚未开始开发，原型评估不代表正式功能已验收。

- [ ] 补齐未决业务规则，并将原型已知问题转为正式版验收条件；按开发模块确认对应契约与第 7 节测试边界。
- [ ] 整理可重复运行的原型参考版本和验证记录。

### 2. 工程基础

- [ ] 建立 React Router v7 + Workers 正式工程，配置类型检查、构建和 Workers Vitest 测试入口。
- [ ] 按页面或流程迁移原型的展示组件、布局、样式和已定稿交互，适配 loader / action 与真实数据；正式工程不依赖原型目录，不沿用演示认证和权限。
- [ ] 配置隔离的 staging / prod Worker、D1、私有 R2 和 Secrets；本地开发使用 `6120` 端口并复用已有实例。
- [ ] 落地 D1 迁移、唯一键和外键约束，准备虚构成员、自行生成的视频与字幕测试夹具。

### 3. 邀请、账号与管理

- [ ] 打通邀请码注册、用户名密码登录、退出和服务端访问控制，验证一次性消费、额度并发、CSRF、限流和 Turnstile。
- [ ] 完成通行密钥、TOTP、会话管理、改密、恢复码和一次性重置链接，按确认规则处理旧会话与认证设备。
- [ ] 完成邀请码管理、成员与邀请链查询、额度调整、角色变更和封禁；验证管理员权限及确认后的连带范围。

### 4. 片库与播放闭环

- [ ] 完成离线导入 CLI：manifest / TMDB 双语资料、MP4 格式与 faststart 预检、字幕转 VTT、R2 / D1 挂接及幂等重试。
- [ ] 将访客入口、成员首页、片库网格与时间轴、作品和选集页面接入正式数据，验证搜索、资料回退、海报和单集剧照状态。
- [ ] 适配已有 ArtPlayer 集成，接入短时播放 token、自动续期、R2 Range 和中英文字幕授权；验证拖动、键盘控制及两小时播放不中断。

### 5. 观看进度、片单与讨论

- [ ] 完成进度上报、跨设备继续观看、自动 / 手动已看状态和下一集提示，按确认规则处理并发与迟到上报，修正切集起点和继续观看漏项。
- [ ] 将作品收藏、有序片单和站内公开读取接入正式数据，验证所有者写权限、私有片单隔离、重排一致性和确认后的播放队列。
- [ ] 将评论、回复、赞踩、排序、分页和发送反馈接入正式后端，验证讨论归属、持久化、正文安全及待确认的配套规则。

### 6. 运维与上线验收

- [ ] 完成每日 D1 → R2 备份及加密 WebDAV 副本，验证失败处理、保留清理和手动恢复；确认媒体冷备与历史解密密钥可用。
- [ ] 在 staging 完成端到端验收：未登录 / 越权访问、封禁与续期、并发幂等、日志脱敏、noindex、备份恢复及真实平台限制。
- [ ] 验证目标规模下的播放体验和预算，补齐本地启动、部署及恢复说明，再发布 v1。

HLS、ASS 渲染、弹幕、同时播放数限制、邮件和 OAuth 登录等范围外功能不纳入本清单；完整范围以需求文档为准。

## 技术栈（计划）

- 运行时：Cloudflare Workers
- 框架：React Router v7（框架模式）
- 数据库：Cloudflare D1
- 媒体存储：Cloudflare R2（私有）
- 播放器：ArtPlayer

本地开发和部署步骤会在工具链确定后补充。
