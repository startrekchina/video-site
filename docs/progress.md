# 项目进展简报

**更新日期**：2026-10-16（北京时间）

**当前阶段**：个人记录与社区（第五阶段）。

**可体验环境**：[本地入口](http://localhost:6120/)（需已有开发服务，启动方式见 [README](../README.md#本地开发)）；[测试站](https://video-development.startrekchina.org)已完成 `dev` 云端自动发布，公开入口、匿名保护和静态资源烟测通过；正式站尚未发布。

**本次汇总范围**：第五阶段的自动保存观看进度已发布到测试站：播放中每 15 秒、暂停、播完、切到后台或离开时保存位置，换设备打开同一集从上次位置继续；播放页可“标记为已看”，作品页每集和电影可标记已看/未看。两台设备同时操作时，较旧的一方会被拒绝并刷新为最新状态，不会把旧数据写回。你确认了原型里的三条规则：回看不会取消“已看完”、手动已看记为看到结尾、没有片源的集也能手动标记。本地与测试站浏览器验证全部通过，测试站虚构数据已清理。第四阶段已收尾，剩余性能缺口按你的决定持续观察。本次没有 production 操作。

## 2. 本期可体验的成果

播放不再签发独立凭证：视频与字幕的每次请求都按你当前的登录会话实时检查，退出、撤销或封禁后新的请求立即被拒；本地调用预算为播放页 7→6、视频分段 4→3 次数据库往返，并且每次分段只读一次存储（原先先查元数据再读取）。云端收益尚未测量。
