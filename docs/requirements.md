# 星际舰队档案馆 · 核心需求（A）

由开发者维护产品目标与范围；Agent 在 [B 详细需求](detailed-requirements.md)中细化规则与验收，不能扩大 A。协作与更新规则见 [AGENTS.md](../AGENTS.md)。

## 产品目标

为《星际迷航》中文粉丝小圈子提供邀请制私人观看站，集中观看作品、记录进度和分享片单。站长利用业余时间维护，面向几百名成员、50 路以内同时播放，月总预算不超过 50 美元。

## v1 核心能力


| 编号       | 核心需求                                             |
| -------- | ------------------------------------------------ |
| A1 私人访问  | 片库、播放和成员内容仅对有效成员开放；访客只看公开介绍和账号入口，全站不被搜索引擎收录。     |
| A2 账号与安全 | 成员可以安全登录、管理自己的账号与会话、自助找回密码，并收到必要安全通知。            |
| A3 片库与播放 | 成员可以浏览、搜索和查看作品资料，顺畅观看电影与剧集、切换简体或繁体的中文、中英双语字幕和已有的清晰度；媒体不能绕过成员权限访问。 |
| A4 进度与片单 | 自动记住进度并跨设备续看，支持已看标记、收藏，以及有序片单的整理、站内分享和播放。        |
| A5 成员讨论  | 成员可以在播放页评论、回复和赞踩，发送弹幕并屏蔽不想看的弹幕；管理员可以删除违规讨论和弹幕。                    |
| A6 邀请与管理 | 每个普通成员能够邀请其他人，但额度有限。管理员管理成员、邀请关系、额度与角色，并处理封禁和解封。 |
| A7 导入与运维 | 站长负责片库导入、专用网页备份及数据安全恢复；测试环境不影响正式服务。staging 与 prod 分别通过 Cloudflare Workers 的 GitHub 集成，从远程仓库的 `dev` 与 `main` 分支自动构建和部署，不以本机源码或构建产物上传作为常规发布方式。 |
| A8 界面体验  | 简体中文界面沿用已确认原型的档案馆风格，适配桌面、手机和基本无障碍操作；首次生产发布后增加简体中文（zh-CN）与繁体中文（zh-TW）切换，界面、作品资料和字幕一起切换。 |




## v1 范围边界

仅覆盖既定片库，不增加新内容收录或网页内容管理。详细流程、默认值和[范围外清单](detailed-requirements.md#8-范围外后续版本)由 B 承接；A 的概括不撤销已确认规则，也不授权增加能力。
