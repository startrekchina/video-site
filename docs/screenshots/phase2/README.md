## 交互核对

- 关于页 200，未知路径 404，HTTP 测试同时检查安全头和禁止收录。
- 页脚原生单选按钮可选择系统 / 浅色 / 深色；跟随系统时，模拟系统由浅到深再到浅，页面同步变化；显式主题在刷新后保留。
- 顶栏和 D 键切换主题；输入元素获得焦点时 D 不切换。主题初始化脚本位于样式前，深色刷新未捕获 hydration 异常。
- 桌面首页宽列 1152 px，切到关于页后顶栏及内容窄列 768 px；导航切换后回到页顶。
- 关于页滚动后显示回到顶部按钮，点击并等平滑滚动结束后 `scrollY=0`、按钮隐藏。
- 访客只显示公共导航和登录入口，没有搜索、账号、片库或管理员入口；手机不显示成员胶囊。胶囊组件接收导航 props，真实成员数据与权限接入在认证阶段验收。
- 浏览器捕获的 `error` / `unhandledrejection` 为空，没有 Vite 错误遮罩；已检查字体加载和主题更新。

首页目前是工程入口；当时展示的登录、注册及恢复链接尚无真实业务。正式认证页按新需求接入，旧 `/recover` 和管理员重置流程不再迁移。此次验收不代替新认证、片库、播放及 staging 验收。
