## 原型迁移与必要差异

- 星图、手机登舰指南、海报/剧照、舞台/刻度尺、网格/时间轴和基础控件迁入 app，正式工程不依赖 prototypes。账号和片库来自真实 loader，未迁入模拟身份或业务账本。
- 正常虚构本地账号通过实际登录表单进入账号页；访客不展示片库或搜索入口。成员首页无观看记录时按 SNW/TNG/TOS S01E01 配置显示真实可播起点；缺片源不生成假入口。
- 全站搜索修复后恢复分组、滚动结果、选中/Enter 提示、真实成员作品摘要和已实现的页面/主题命令；复用现有 Dialog 与原生键盘处理，不新增依赖。受保护 GET 结果页继续保留，Ctrl/⌘K、/、焦点、箭头、Enter/Escape、输入 D 不切主题及筛选保留视图/排序通过。
- 修复后按实际播放器宽度收起次要控件：不超过 480px 隐藏画中画/网页全屏，不超过 360px 再隐藏音量图标，保留播放、时间、设置和原生全屏；键盘/设备音量可用。手机胶囊恢复 sm 断点，短屏按实际顶部高度封顶，详见修复记录。
- 进度/收藏只读；写入、片单队列、完整继续观看和讨论按第五阶段开发。字幕/VTT 与视频共用同单元 token，播放器换单元重建，取消旧续期。
