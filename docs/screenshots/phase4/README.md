## 原型迁移与差异

- 最终本地检查：`pnpm typecheck`、168 项应用测试、14 项工具测试和 `pnpm build` 通过；41 个客户端文本产物没有本机密钥值、对象键或 Worker 绑定。Better Auth 自带的环境变量名称不包含密钥值。
- 星图、手机登舰指南、海报/剧照、影院舞台及刻度尺、时间轴与原型基础布局复制到正式 `app/`，没有正式工程对 `prototypes/` 的运行依赖。展示控件复用既有 token、字体、主题与响应式规则。
- 登舰指南修正原型旧认证文案：必须验证邮箱，邮箱找回密码，二步备用码只替代第二因素，不提供管理员重置。邀请码原值带入注册，不做破坏性大写转换；星图登录入口进入真实登录页，不使用模拟身份。
- 成员首页、片库、作品、选集和播放页使用 D1 loader 与公开 DTO；首页起点由部署配置映射到 manifest 的 SNW（103516）、TNG（655）、TOS（253）S01E01，缺片源不生成假播放入口。收藏/观看状态只读，写入及完整继续观看/下一集、片单队列和讨论仍按第五阶段实现。
- 正式成员导航包含片库与账号管理，窄于 1024 px 时使用现有底部菜单承载，避免在较窄平板上挤压全部链接；这是正式权限导航适配，实际视口仍待浏览器核对。
- 浏览网格、时间轴、年份排序、搜索和切季保留；搜索由 GET 表单提交给服务端，输入上限 100 字符。作品页与播放页保留详情顶栏、资料、上一/下一可播单元和当前季选集；缺媒体明确提示，不沿用原型测试片段冒充片源。
- 播放页没有迁入模拟 token gate、进度账本或评论。键盘使用 ArtPlayer 原生空格/方向键，并沿用 F/M/C 扩展。中文字幕优先，可切换其他轨道或关闭；字幕与视频共用同一单元的 token。续期状态保存在当前播放器实例，换单元重建实例并读取目标起点。
