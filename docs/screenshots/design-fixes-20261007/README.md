## 工程与平台验证

- 最终 `pnpm typecheck`、175 项应用测试、15 项工具测试、`pnpm build:staging`、staging `cf deploy --prebuilt --mode staging --dry-run` 通过。HTTP 检查覆盖成员错误页身份、访客隔离及全局作品摘要不返回内部对象字段。
- 最终构建的 62 个客户端文本产物及改动文件中无已知密钥/内部资源配置值。正式工程不依赖 `prototypes/`。
- 本地手动触发原续期回调，两次实际 POST 均 200。暂停换源保持 42 秒及英文轨道；播放换源保持 42.52 秒之后的位置、播放状态与英文轨道。没有修改时钟或续期间隔；这两次手动检查不作为自然长时播放证据。
- staging 更新后 fetch/scheduled 生效，启动 62ms；cf 只读确认 D1/R2/既有 Secrets、request signal、日志脱敏与关闭 workers.dev 保持，官方 API 只读确认五分钟 Cron 保留。没有重新上传片源、初始化数据库或修改 production。
- staging 浏览器读取真实统计、解码 7260 秒生成视频并取得媒体 206，可见横屏控制条在视口内。匿名 Chrome 请求中，公开首页/关于返回 200，受保护页面跳转登录、无作品/统计泄漏，媒体拒绝为 401，安全头通过。Node/curl 直连曾发生 TLS 连接重置，最终以上述实际浏览器请求完成 HTTP 复验。
- 此前 staging 的 121 分钟自然播放证据仍保存在[原记录](../phase4/staging-playback-report.json)，属于修复前功能基线；本轮没有宣称重新跑完两小时。修复后的换源、字幕同步和布局另按上述结果记录。
