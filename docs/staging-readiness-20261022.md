## 邀请与封禁迁移

原 staging 库用三个本次专用虚构成员及短期会话执行，未操作真实成员、未发邮件。会话夹具不计作注册或登录验收。

| 场景 | 结果 |
| --- | --- |
| 过期/作废邀请码释放额度，已用码继续占用 | `occupied = 1`，符合预期 |
| 相同 `operationId` 重试发码 | 相同 ID，数据库只留一条 |
| 他人作废邀请码 | `409`，原码保留 |
| 跨来源写入 | `403` |
| 封禁迁移的触发器 | 仅作废有效未用码；过期、已用及既有作废记录原样保留，旧会话删除 |
| 已缓存会话封禁后请求 | 邀请、媒体 Range、HEAD 均 `401`，不泄露范围 |
| 解封 | 不恢复旧会话或已作废码 |
| 邀请人与成员来源错配 | 实际 staging 约束拒绝 |
| 其他正常成员媒体读取 | `206`，16 字节正确，私密缓存头保留 |

封禁和解封状态由定向 SQL 触发，用于验证已部署增量迁移；不计作管理员网页操作或通知投递验收。管理员入口的既有阶段证据按未变实现复用。

## 请求性能与并发

使用同一专用会话，五条路径轮流采样，每条 20 次。传输为系统 curl 经本机已有代理，每个样本新建连接；会话缓存有效，不代表真正 Worker 冷启动或手机冷缓存。全部 100 次响应符合预期，接入机房均为 HKG。

| 路径 | TTFB 中位数 | P95 | 最大值 |
| --- | ---: | ---: | ---: |
| 成员首页 HTML | 421 ms | 1,434 ms | 1,505 ms |
| 剧集 HTML | 492 ms | 1,498 ms | 2,513 ms |
| 播放页 HTML | 466 ms | 1,486 ms | 2,509 ms |
| 播放页 `.data` | 377 ms | 1,118 ms | 1,400 ms |
| 64 KiB 媒体 Range | 458 ms | 1,510 ms | 1,672 ms |

20 个超过一秒的样本中，18 个 TLS 完成时间超过一秒；扣除 TLS 阶段后的等待中位数 241 ms、P95 471 ms，另有两次超过 800 ms。扣除结果仍包含网络传输，不能等同服务端执行时间；没有请求级 D1/R2 探针，不能归因全部尾延迟或与旧样本作同条件性能收益比较。

三轮各 50 个并发、每请求读取 64 KiB 的 Range 全部为 `206` 且字节数正确，共 150 次成功。三轮中位数为 498/465/479 ms，P95 为 1,553/1,546/1,476 ms。该结果验证有限并发请求，不等于 50 路真实码率持续播放、解码或容量验收。

平台版本元数据的 `startup_time_ms = 34` 仅为上传版本启动指标，不代表完整冷请求延迟。当前浏览器插件连接不稳定，且只读页面环境不开放 Navigation Timing；无可调用的性能 trace 工具，未取得新的手机冷缓存 LCP、真正冷启动或全部敏感插件独立成本数据。性能整体验收保持未完成。

浏览器读取 Cloudflare 控制台的最近 24 小时汇总：1.89k 次调用，静态资源缓存命中率 98.52%；内存 P50/P90/P99/P999 分别为 23.63/24.87/25.19/25.21 MB，内存超限与 CPU 超限均为 0。旧版本 `57bfcb5c` 有一次未捕获异常，原基线 `04a1ab3b` 和临时恢复版本 `305fcaaf` 均为 0。汇总混合历史版本、测试及匿名流量，不能代表成员实际接入分布，也不能把这些内存分位数当作单次备份峰值；控制台时段筛选因浏览器连接超时未完成。

## 规模、费用与剩余条件

官方价格核对日期为 2026-10-22。Workers Standard 基础费 5 美元/月，含一千万请求及三千万 CPU 毫秒，额外请求每百万 0.30 美元、CPU 每百万毫秒 0.02 美元；静态资源请求另按免费规则。[Workers 计价](https://developers.cloudflare.com/workers/platform/pricing/)

R2 Standard 存储每 GB/月 0.015 美元，含 10 GB 免费额度；Class A/B 分别每百万 4.50/0.36 美元，公网出口流量免费。按旧假设总媒体 1,700 GB，存储加 Workers 基础费约为 `5 + (1700 - 10) × 0.015 = 30.35` 美元/月，尚未计入额外操作、CPU、邮件及异地备份费用。多清晰度须按所有档位的合计容量计算。[R2 计价](https://developers.cloudflare.com/r2/pricing/)

D1 Paid 含每月 250 亿读行、5,000 万写行及 5 GB 存储，超额按实际用量计费。额度属于账户共享，其他项目的占用必须纳入考虑。[D1 计价](https://developers.cloudflare.com/d1/platform/pricing/)

当前 CLI 访问账单用量接口返回 `403 Authentication error`。正式媒体各档位总量、实际 CPU/请求用量、邮件与异地备份费用未核定，因此不标记总预算不超过 50 美元/月通过。开发者确认媒体/字幕冷备及当前、历史密钥独立副本尚未准备好；这些仍为上线阻塞。内存只有备份正常完成、未被平台终止的间接证据；WebDAV 直接回读服务仍未完成实测。
